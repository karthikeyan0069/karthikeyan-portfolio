# 🌐 Karthikeyan — Portfolio Website

A modern and responsive **personal portfolio website** built using **HTML and CSS** to showcase UI/UX design skills, web development expertise, and professional contact information.

This portfolio highlights creativity, clean design principles, and user-centered development practices.

---

## 📌 Project Overview

The **Karthikeyan Portfolio Website** is a single-page personal website designed to present professional skills, experience, and contact details in a visually appealing and structured layout.

The website focuses on simplicity, readability, and smooth navigation while maintaining a modern dark-themed aesthetic.

---

## ✨ Features

* 🎨 Modern dark UI design
* 📱 Fully responsive layout
* 🧭 Smooth scrolling navigation
* 🧩 Structured portfolio sections
* 💼 Skills categorization
* 📞 Contact information integration
* ⚡ Lightweight and fast performance
* 📄 Single HTML file implementation

---

## 🛠️ Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling and layout design
* **Google Fonts (Poppins)** — Typography
